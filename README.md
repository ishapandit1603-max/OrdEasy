# 📦 **OrdEasy — AI-Powered Order Intelligence Platform**

> **A multi-agent AI platform that automates end-to-end order processing for Small and Medium Enterprises (SMEs).**

## 🚀 **Project Overview**

**OrdEasy** extracts and validates order data from **emails, PDFs, and spreadsheets** using AI-powered automation. Its **self-healing AI agents** detect and recover processing exceptions while real-time dashboards and an **AI chatbot** provide actionable order insights.

Built with **low-cost and open-source technologies**, OrdEasy aims to make intelligent order automation accessible to SMEs.

## ✨ **Key Features**

- 📄 **Multi-Source Order Extraction** — Emails, PDFs & spreadsheets
- 🔍 **Automated Order Validation**
- 🤖 **Multi-Agent AI Processing**
- 🛠️ **Self-Healing Exception Recovery**
- 📊 **Real-Time Order Dashboard**
- 💬 **AI Chatbot for Order Insights**

## 🛠️ **Tech Stack**

**AI / LLM:** Groq LLaMA  
**OCR:** PaddleOCR  
**Frontend:** React • Recharts  
**Database:** MySQL

## 🔄 **Workflow**

**Emails / PDFs / Spreadsheets** 📥 → **OCR & Extraction** 📄 → **Validation** 🔍 → **Multi-Agent Processing** 🤖 → **Exception Recovery** 🛠️ → **Dashboard & AI Chatbot** 📊💬

## 🎯 **Objective**

To provide SMEs with a **cost-effective, intelligent, and reliable order automation platform** that reduces manual processing and enables faster, data-driven order management.
